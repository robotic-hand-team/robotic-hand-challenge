# `simulation/`: MuJoCo digital twin

Simulation quick start: [README.md](../../simulation/README.md)

This folder holds a physics simulation of the Inspire hand grasping the two VEGABAR sensors. It
serves three purposes:
- **generating training data** with exact ground truth, which the real hand can't measure
- **testing grasp strategies** safely
- **visualising** tactile data and pose estimates in 3D

The simulated hand exposes the same registers as the real one (`ANGLE_SET`, `FORCE_SET` and
`SPEED_SET` in; `ANGLE_ACT`, `FORCE_ACT`, `CURRENT` and `STATUS` out). It records sessions in
exactly the real dataset format.

> Run every `hand_sim` command **from inside `simulation/`** as a module: `python -m hand_sim.<name>`.
> On macOS, open the viewer with `mjpython` instead of `python`.

## `hand_sim/` modules

| Module | Role |
|---|---|
| `config.py` | All constants: solver settings, objects (mass, grasp pose, pivot), sensor groups, timings, `HAND_SIDE` |
| `scene.py` | Loads the XML and patches it at load time: collisions, position servos per DOF, solver |
| `left_hand.py` | Builds the **left** hand by mirroring the right-hand model |
| `world.py` | Simulation state shared by viewer and headless runs: model, hand, tactile model, object carriers |
| `hand.py` | Emulates the hand's Modbus registers; `FORCE_ACT` comes from contact torques |
| `tactile.py` | 17 simulated tactile groups, with patches derived from the live mesh |
| `policy.py` | `ScriptedGraspPolicy` (baseline) and an `NNPolicy` stub |
| `episode.py` | Random handovers: the carrier brings the object, the policy grasps, the carrier releases, the hand holds |
| `recorder.py` | Writes sessions in the real format plus `object_pose.csv` |
| `generate_dataset.py` | Parallel version of `recorder.py` (about 300 sessions in about 70 s) |
| `pose_import.py` | Replays a `pose/` estimate (`<session>.sim.json`) in the simulation |
| `run.py` | Interactive viewer; commands are typed in the terminal |
| `tactile_panel.py`, `taxel_overlay.py` | Thermal heat-map panel / glowing taxels on the 3D hand |
| `classifier_bridge.py` | Shows the live Sensor A/B prediction in the viewer |
| `assets.py` | Object STL → simulation meshes (mm → m, CoACD convex parts) |
| `physics_audit.py` | Physics acceptance test: geometry, penetration, self-collision, success rate |
| `rebuild_hand_collision.py`, `calibrate_tactile.py` | Development tools |
| `test_smoke.py` | Smoke tests (plain functions, no pytest needed) |

## Common commands

```bash
cd simulation
python -m hand_sim.assets                         # once: build object meshes
python -m hand_sim.test_smoke                     # quick regression test
python -m hand_sim.run                            # viewer (type `help` in the terminal)
python -m hand_sim.run --demo                     # random handovers in the viewer
python -m hand_sim.run --pose ../pose/output/vegabar38/20261016_204609.sim.json
python -m hand_sim.episode --episodes 100         # headless, prints success rates
python -m hand_sim.generate_dataset --episodes 300 --out ../models/dataset_sim --workers 8
python -m hand_sim.physics_audit --episodes 50    # run before and after any physics change
```

Viewer terminal commands include `obj vegabar_38`, `close`, `release`, `status`, `open`,
`attach` and `tactile`.

The viewer accepts these options:
- `--object`, `--seed`
- `--heatmap panel|3d|both|off`, `--heatmap-size`, `--heatmap-gain`, `--heatmap-stride`
- `--no-classifier`

## Settings via environment variables

| Variable | Effect |
|---|---|
| `HAND_SIDE=right` | Simulate the right hand. The default is `left`, matching the team's current hardware |
| `CLASSIFIER_SUFFIX` | Which Sensor A/B model the viewer shows: `""` (real), `_sim` or `_combined` (default) |

## Things to know

- **Hand frame:** the palm faces +x, the fingers point +z, and the thumb is on the +y side. Joint position 0 is open, which is angle 1000 on the real hand.
- **MuJoCo DOF order** differs from the hardware: `thumb_yaw, thumb_pitch, index, middle, ring, pinky`.
- **Baseline success rates:** the scripted grasp succeeds roughly 65–70% of the time with VEGABAR 29 and 80–85% with VEGABAR 38. Most failures are the object rotating out of the fingers while they close.
- **Comparing two configurations:** give every episode its own rng, `np.random.default_rng([seed, k])`, and compare paired results. Otherwise the differences are mostly noise.
- **Heat-map outline:** `tactile_panel.py` takes the hand outline from `frontend/public/hand.png`. Keep that file.
- **Also used by the dashboard:** `backend/` loads the MuJoCo hand model from `hand_sim` (`scene.py`, `config.py`), `Inspire_hand/` and `objects/` to build its 3D twin. Changes here affect the dashboard too.
